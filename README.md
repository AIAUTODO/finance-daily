# 金融行情自动页

纯数据行情汇总页，零人工介入全自动生成。部署目标：Cloudflare Pages（`finance.ilong.dpdns.org`）。

## 特点

- **只含可自动化内容**：15 个品种的最新价、涨跌幅、日高低、持仓，以及金银比/金油比/布-WTI 价差等派生指标
- **不含任何分析文字**：没有主观判断、没有操作建议，避免 AI 生成错误内容
- **数据源**：新浪财经公开行情接口 + 中国货币网人民币中间价
- **零本地依赖**：脚本在 Windows 和 GitHub Actions（Ubuntu）上行为一致

## 本地运行

```bash
python build.py
```

生成 `finance.html` 与内容相同的 `index.html`，直接用浏览器打开即可预览。

## 自动更新机制

`.github/workflows/deploy.yml` 配置：

- 每天 UTC 23:00（北京 07:00 / 迪拜 03:00）自动运行
- 抓行情 → 生成 `finance.html` 和 `index.html` → 自动提交回仓库
- Cloudflare Pages 监测到仓库变更 → 自动重新部署，`finance.ilong.dpdns.org` 直接指向 `finance.html`

**为什么选这个时间**：外盘 NYMEX/COMEX 在北京时间 05:00 收盘、06:00 开始新交易日，上海夜盘 02:30 收盘。07:00 运行时两侧数据都已定型，既拿到完整隔夜收盘，又赶在上班前。

时间栏同时显示北京、纽约、伦敦、迪拜四个时区，自动处理夏令时。

想改时间就改 cron 表达式（注意是 UTC 时间，北京时间减 8 小时）。

## 数据源说明

| 代码 | 品种 | 字段位置 |
|------|------|---------|
| `fx_susdcny` | 在岸人民币 | 0=时间 1=最新 3=昨收 6=高 7=低 |
| `fx_susdcnh` | 离岸人民币 | 同上 |
| `DINIW` | 美元指数 | 0=时间 1=最新 3=昨收 6=高 7=低 |
| `hf_*` | 外盘商品/贵金属 | 0=最新 4=高 5=低 6=时间 7=昨收 |
| `nf_*` | 内盘期货主连 | 3=高 4=低 8=最新 10=昨结 13=持仓 |

中间价来源：中国货币网 `ccpr.json`，字段 `vrtEName=USD/CNY`。

## 容错设计

- 单个品种抓取失败 → 跳过并记日志，页面底部标注「本期未取到」
- 中间价抓取失败 → 跳过，不影响其余数据
- 全部品种失败 → 脚本退出码 1，Actions 报错，不会覆盖上一版页面

## 新增品种

改 `build.py` 里的 `SYMBOLS` 列表，加一行：

```python
("hf_XX", "xx", "显示名", "单位", "分组名"),
```

分组需在 `GROUP_COLORS` 里配色，并在 `render()` 的 `for group in [...]` 列表里加上分组名。
